# Describe Your Ex in One Word: "Placeholder"

## The word

**Placeholder.**

A placeholder is the thing that holds a spot only until the real one
arrives — the grey silhouette in the template, the dummy text standing
in for the words that actually matter. That is the whole relationship,
summed up in hindsight: not the destination, just something occupying
the space in the layout of your life until the genuine article showed
up to replace it.

It lands because it is not an insult you shout, it is a filing
decision. Anyone who has had an ex recognises the demotion instantly:
from headline to filler. One word, spelled plainly, no punctuation
tricks, and the joke arrives with the word itself.

## How the program works

`main.py` is a small, standard-library-only Python program. It writes
the single word `Placeholder` as UTF-8 text to `/output/entry.txt`
(creating the directory if needed) and exits. The word is a fixed
constant, so the program is fully deterministic and offline: two runs
produce byte-identical output, well inside the gate's 1–111 character
limit.

Run it with:

```sh
python3 main.py
```
